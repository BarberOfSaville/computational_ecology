~INATURALIST DOWNLOAD: README~

PROJECT GOAL: quickly download and compile iNaturalist observation data for a chosen location and taxa. The outputted CSV contains a list of all species (common/scientific names, genus, family, order) and the number of observations for a given taxon and place. An additional script allows a user to merge two output CSVs into one, with columns for number of observations from each CSV as well as a combined number of observations. 

PURPOSE: I am studying bee communities in Manhattan and the Bronx. While iNat observations are not the most sound authority for what exists in a place, I wanted to compile a list of the bee species documented on iNat for both counties as a reference for myself. I knew it would also be a useful Python exercise for learning how to utilize APIs.  

NOTE: Timeout errors are frequent. I'm working on this.


SCRIPTS

1. inat_dex_master.py	iNaturalist Data Downloader

HOW TO USE

The user should run the inat_dex_master.py function. They should input their desired taxon ID, place ID, and final filename where indicated at the top of your script. These are the only fields they should adjust. 

Taxon ID and place ID can be found by using iNaturalist.com's explore page and inputting the desired taxon and place. Both parameters can then be taken from the URL. 

One could adjust parameters other than taxon ID and place ID, but these were the two I was the most interested in for this project.  


2. inat_merge.py	iNatutalist CSV Merger

This function merges two output CSVs from inat_dex_master.py into one, adding columns for number of observations of each species from each of the parents, and a column for combined number of observations. Inputs are the two desired CSVs, and a filename for the output.


3. inat_download_function.py

This function is called by the master iNat script to request iNat data from the iNaturalist API given the inputted parameters and returns them as a dictionary.


4. inat_list_function.py

This function is called by the master iNat script to make a dataframe out of the dictionary returned by iNat download. Counts the number of observations per species, and calls iNat index to gather additional data for each species. Then, outputs the dataframe as a CSV. 


5. inat_index_function.py

This function, called by inat_list_function.py, accepts an iNat species ID and returns a dictionary containing common name, species, genus, family, and order by querying the iNaturalist API. These categories are then added to the dataframe generated by inat_list_function.py.


6. bee_dex.py

This is the script where I called my functions to do the thing I wanted to do: download the number of observations for all bee species in Manhattan and the Bronx, and then merge these two datasets into one combined CSV.


Other scripts, functions and notebooks: Me testing and/or debugging at various stages. Not particularly useful except to see me play around with things.
